## 1. ภาพรวมระบบ

NU Volunteer คือระบบบริหารจัดการกิจกรรมจิตอาสาของมหาวิทยาลัยนเรศวร ครอบคลุมตั้งแต่การประกาศกิจกรรม
การลงทะเบียนเข้าร่วม การเช็คอิน/เช็คเอาต์หน้างานด้วย QR code การบันทึกและรับรองชั่วโมงจิตอาสา
การออกใบประกาศนียบัตรพร้อมหน้าตรวจสอบสาธารณะ (verify) และการประเมินเกณฑ์ชั่วโมงจิตอาสาสำหรับ
**ผู้กู้ยืมกองทุนเงินให้กู้ยืมเพื่อการศึกษา (กยศ.) — เกณฑ์ 36 ชั่วโมง/ปีการศึกษา**

ระบบรองรับ **2 ภาษา** (ไทย/อังกฤษ สลับได้จากแถบหัวเรื่อง), **โหมดมืด**, และ **4 สไตล์การแสดงผล**
(พาสเทล / แคนดี้ / นีออน / มินิมอล) — ดูรายละเอียดใน `DESIGN-SYSTEM.md`

## 2. คู่มือฝั่งนิสิต

### 2.1 สมัครสมาชิก / เข้าสู่ระบบ
- **อีเมลต้องเป็นโดเมนมหาวิทยาลัยเท่านั้น** (`@nu.ac.th`) — ระบบตรวจทั้งฝั่งหน้าเว็บและฝั่งเซิร์ฟเวอร์
  (error code `EMAIL_DOMAIN`); อีเมลอื่นจะสมัครไม่ผ่าน
- **รหัสผ่าน** ต้องยาวอย่างน้อย 8 ตัวอักษร และมีทั้งตัวอักษรและตัวเลข (`WEAK_PASSWORD`)
  หน้าสมัครมีตัววัดความแข็งแรงรหัสผ่านแบบเรียลไทม์
- **การสมัครมี 3 ขั้นตอน**: ① ข้อมูลบัญชี (ชื่อ-อีเมล-รหัสผ่าน) → ② ข้อมูลนิสิต (รหัสนิสิต, คณะ, สถานะผู้กู้ยืม กยศ.)
  → ③ ยืนยันและยอมรับข้อกำหนดการใช้งาน (`TERMS_REQUIRED` ถ้าไม่ติ๊ก)
- อีเมลที่มีบัญชีอยู่แล้วจะได้ `EMAIL_TAKEN`
- **ลืมรหัสผ่าน**: กรอกอีเมล → ระบบส่งลิงก์รีเซ็ตทางอีเมล **อายุ 30 นาที** → ตั้งรหัสใหม่
  (ระบบตอบข้อความเหมือนกันทุกกรณี เพื่อไม่ให้ใช้ฟอร์มสแกนหาว่าอีเมลใดมีบัญชี)
- **2FA (การยืนยันสองชั้น)**: เปิดได้ที่ ตั้งค่า → ความปลอดภัย เลือก TOTP (แอป Authenticator) หรือ SMS
  ระบบจะสร้าง **รหัสสำรอง 8 ชุด** ให้เก็บไว้ใช้ยามเข้าถึงอุปกรณ์หลักไม่ได้

### 2.2 ค้นหาและลงทะเบียนกิจกรรม
- หน้า **ค้นหากิจกรรม** มีช่องค้นหา + แถบตัวกรองหมวดหมู่ (แถบเลื่อนแนวนอนบนมือถือ)
- สถานะที่นั่งแสดงเป็นป้ายสี: **เปิดรับสมัคร** (เขียว) · **ใกล้เต็ม** (ส้ม, ≥80%) · **ที่นั่งเต็ม** (แดง) · **ปิดรับสมัคร**
- กด **ลงทะเบียน** → ยืนยันในโมดัล → สถานะเริ่มต้นคือ **รออนุมัติ** จนกว่าผู้จัดจะกดอนุมัติ
- กิจกรรมบางรายการมี **สิทธิประโยชน์พิเศษ** (เช่น นับชั่วโมงพิเศษ, ของที่ระลึก) แสดงในหน้ารายละเอียด
- กด ♡ เพื่อบันทึกกิจกรรมที่สนใจไว้ในรายการโปรด

### 2.3 เช็คอิน / เช็คเอาต์ด้วย QR code
1. ไปที่หน้ากิจกรรมในวันงาน กด **สแกน QR**
2. อนุญาตให้เบราว์เซอร์ใช้กล้อง (ต้องเปิดผ่าน **HTTPS** เท่านั้น)
3. หันกล้องไปที่ QR ของผู้จัด — เมื่อสำเร็จจะมีขอบเรืองแสง เสียง และการสั่น (บนมือถือ)
4. ระบบตรวจ **GPS** เทียบพิกัดสถานที่จัดกิจกรรม หากอยู่นอกรัศมีจะแจ้งเตือนและบันทึกไว้ให้ผู้จัดพิจารณา
5. เช็คเอาต์ด้วยวิธีเดียวกันเมื่อจบกิจกรรม — ระบบคำนวณชั่วโมงจากช่วงเวลาเช็คอิน–เช็คเอาต์

> QR มีการหมุนรหัสเป็นระยะและมีเวลาหมดอายุ — สแกนภาพถ่ายหน้าจอเก่าไม่ผ่าน

### 2.4 หลักฐานและชั่วโมงสะสม (เกณฑ์ กยศ.)
- หลังเช็คเอาต์ สถานะจะเป็น **รอหลักฐาน** → อัปโหลดรูป/ไฟล์หลักฐานในหน้า **การลงทะเบียน**
- สถานะหลักฐาน: รอตรวจ → **หลักฐานผ่าน** / **หลักฐานไม่ผ่าน**
- หน้า **ชั่วโมงจิตอาสา** แสดงแถบความคืบหน้าเทียบเกณฑ์ **36 ชม./ปีการศึกษา** สำหรับผู้กู้ยืม กยศ.
  พร้อมแยกยอดตามหมวดหมู่กิจกรรมและภาคการศึกษา

### 2.5 ยื่นอุทธรณ์
หากชั่วโมงถูกปฏิเสธหรือไม่ตรงกับที่เข้าร่วมจริง กด **ยื่นอุทธรณ์** ที่รายการนั้น แนบเหตุผลและหลักฐานเพิ่มเติม
สถานะอุทธรณ์: **รอพิจารณา** → **อุทธรณ์ผ่าน** / **อุทธรณ์ไม่ผ่าน** (แจ้งเตือนกลับทางระบบและอีเมล)

### 2.6 ใบประกาศนียบัตร
- ใบประกาศออกอัตโนมัติเมื่อชั่วโมงได้รับการรับรองครบตามเงื่อนไขกิจกรรม
- กด **ดูตัวอย่าง** เพื่อพรีวิว และ **ดาวน์โหลด** เป็นไฟล์
- ใบประกาศทุกใบมีรหัสตรวจสอบและ **ลิงก์หน้า verify แบบสาธารณะ** ให้หน่วยงานภายนอกตรวจสอบความถูกต้องได้

### 2.7 โปรไฟล์ · การแจ้งเตือน · แชท · ปฏิทิน
- **โปรไฟล์**: แก้ชื่อ คณะ รหัสนิสิต และอัปโหลดรูปโปรไฟล์ (รูปจะคงอยู่ข้ามการเข้าใช้งาน)
- **การแจ้งเตือน**: จัดกลุ่มตามวันและรวบยอดตามประเภท (อนุมัติ · เตือนความจำ · ข้อความ · ใบประกาศ · กยศ. · ระบบ)
  ตัวเลขบนกระดิ่งนับเฉพาะรายการที่ยังไม่อ่าน
- **แชท**: คุยกับผู้จัดกิจกรรมหรือแอดมิน ลบข้อความของตนเองได้ (มีปุ่ม *เลิกทำ* ทันทีหลังลบ)
- **ปฏิทิน**: มุมมองรายเดือน/รายสัปดาห์ แสดงเฉพาะกิจกรรมที่ลงทะเบียนไว้ พร้อมแถบ "กิจกรรมที่กำลังจะถึง" ด้านล่าง

## 3. คู่มือฝั่งผู้จัดกิจกรรม

### 3.1 สร้าง / แก้ไข / ลบกิจกรรม
- กด **สร้างกิจกรรม** แล้วกรอก: ชื่อ, หมวดหมู่, วันเวลาเริ่ม-สิ้นสุด, สถานที่ + พิกัด, จำนวนที่นั่ง,
  ชั่วโมงที่ได้รับ, รายละเอียด, สิทธิประโยชน์พิเศษ (ถ้ามี)
- **ช่องภาพ 4 ช่อง**: ภาพหลัก (hero) · ภาพกิจกรรม 1 · ภาพกิจกรรม 2 · แผนที่ — ลากไฟล์วางได้โดยตรง
  ช่องที่ยังไม่มีรูปจะแสดง placeholder และแผนที่จะ fallback เป็นภาพนิ่ง
- แก้ไขได้ทุกเมื่อ; การลบกิจกรรมที่มีผู้ลงทะเบียนแล้วต้องยืนยันซ้ำ และระบบจะแจ้งเตือนผู้ลงทะเบียนทุกคน

### 3.2 จัดการผู้สมัคร
- หน้า **ผู้เข้าร่วมกิจกรรม** แสดงรายชื่อพร้อมสถานะ: รออนุมัติ · อนุมัติแล้ว · เช็กอินแล้ว · รอหลักฐาน · เสร็จสิ้น · ยกเลิก · ไม่มาตามนัด
- อนุมัติ/ปฏิเสธได้ทีละรายการ หรือ **เลือกหลายรายการพร้อมกัน (bulk actions)** ด้วยช่องติ๊กหน้าแถว
- ส่งออกรายชื่อเป็น CSV ได้จากปุ่มมุมขวาบน

### 3.3 คำขอยกเลิกและอุทธรณ์
- **คำขอยกเลิก** จากนิสิตจะเข้ามาพร้อมเหตุผล — อนุมัติแล้วที่นั่งจะถูกคืนเข้าระบบอัตโนมัติ
- **คำขออุทธรณ์** ตรวจหลักฐานเพิ่มเติมแล้วให้ผลได้ทันที หรือส่งต่อให้แอดมินตัดสิน

### 3.4 อนุมัติหลักฐาน / ชั่วโมง
เปิดหลักฐานที่นิสิตอัปโหลด ตรวจแล้วกด **ผ่าน** / **ไม่ผ่าน** (ระบุเหตุผลเมื่อไม่ผ่าน)
ชั่วโมงจะเข้าสู่ยอดสะสมของนิสิตทันทีที่กดผ่าน

### 3.5 สถิติ · รีวิว · รายงาน
- แดชบอร์ดสรุป: จำนวนผู้สมัคร อัตราการเข้าร่วมจริง ชั่วโมงรวม และคะแนนรีวิวเฉลี่ย
- อ่านรีวิว/ความเห็นจากผู้เข้าร่วมได้รายกิจกรรม
- ส่งออกรายงานเป็น CSV หรือสั่งพิมพ์ (เลย์เอาต์พิมพ์ A4 แนวนอน ตั้งค่าไว้แล้วในระบบ)

### 3.6 ปฏิทินของตนเอง
ปฏิทินฝั่งผู้จัดแสดง **เฉพาะกิจกรรมที่บัญชีตนเป็นผู้สร้าง** มุมมองเดือน/สัปดาห์ และแถบกิจกรรมที่กำลังจะถึง

## 4. คู่มือฝั่งแอดมิน

### 4.1 ผู้ใช้งานและบทบาท
- ค้นหา/กรองผู้ใช้ เพิ่มผู้ใช้ใหม่ (โมดัล **เพิ่มผู้ใช้งาน**) เปลี่ยนบทบาท ระงับ/เปิดใช้งานบัญชี
- บทบาทที่กำหนดได้: `student` · `organizer` · `admin` (การสมัครด้วยตนเองจากหน้าเว็บได้เฉพาะ `student`)

### 4.2 หมวดหมู่และคณะ
เพิ่ม/แก้ไข/ลบหมวดหมู่กิจกรรม และรายชื่อคณะ พร้อมส่งออกเป็น CSV และหน้าเปรียบเทียบสถิติรายคณะ

### 4.3 ข่าวสารประชาสัมพันธ์ / แบนเนอร์
สร้างประกาศที่ขึ้นเป็นแบนเนอร์บนหน้าหลักของทุกบทบาท และชุดสไลด์ประกาศต้อนรับ (ทีละขั้น ข้ามได้)

### 4.4 System Log และการเชื่อมต่อระบบ
- **System Log**: บันทึกเหตุการณ์ระบบ รวมถึง **การพยายามเข้าสู่ระบบที่ล้มเหลว** และการถูก rate limit
  (มาจากตาราง `AuthLog` ฝั่ง backend)
- **สถานะอีเมล**: คิวการส่ง สถานะ ส่งสำเร็จ/กำลังส่ง/ล้มเหลว พร้อมปุ่มส่งซ้ำรายฉบับ
- **การสำรองข้อมูล**: รอบสำรองอัตโนมัติ ระยะเก็บรักษา และปุ่มสำรองทันที
- **เซสชัน**: ดูอุปกรณ์ที่ล็อกอินอยู่ และปิดเซสชันอื่นทั้งหมดได้

### 4.5 โหมดปิดปรับปรุงระบบ (Maintenance mode)
เปิดจากหน้าตั้งค่า — ผู้ใช้ทั่วไปจะเห็นหน้าประกาศปิดปรับปรุง ขณะที่แอดมินยังเข้าใช้งานได้ตามปกติ

### 4.6 ตั้งค่าระบบ และโซนอันตราย
- ตั้งค่า: เปิด/ปิดการรับสมัครสมาชิกใหม่, การส่งอีเมลแจ้งเตือน, เกณฑ์ชั่วโมง กยศ., ภาษาเริ่มต้น
- **โซนอันตราย**: รีเซ็ตข้อมูลระบบ และสำรอง/กู้คืนข้อมูล — ทุกคำสั่งต้องยืนยันซ้ำและถูกบันทึกลง System Log

## 5. คำถามที่พบบ่อย (FAQ)

**ถาม: สแกน QR แล้วกล้องไม่เปิด ทำอย่างไร**
1. ต้องเปิดเว็บผ่าน **https://** เท่านั้น (เบราว์เซอร์ไม่ให้สิทธิ์กล้องบน http)
2. กดปุ่มสแกนด้วยตัวเอง — เบราว์เซอร์อนุญาตให้เปิดกล้องเฉพาะเมื่อผู้ใช้เป็นคนกด
3. ตรวจการอนุญาตกล้องของเว็บไซต์ในตั้งค่าเบราว์เซอร์ (Safari: ค่า > เว็บไซต์ > กล้อง)
4. ปิดแอปอื่นที่ใช้กล้องอยู่ แล้วลองใหม่
5. ถ้ายังไม่ได้ ใช้ปุ่ม **เปิดในแท็บใหม่** ที่หน้าสแกน หรือให้ผู้จัดเช็คอินให้ด้วยตนเอง

**ถาม: ลืมรหัสผ่านทำอย่างไร**
กด "ลืมรหัสผ่าน" ที่หน้าเข้าสู่ระบบ → กรอกอีเมล `@nu.ac.th` → เปิดลิงก์ในอีเมล **ภายใน 30 นาที**
ถ้าลิงก์หมดอายุ (`TOKEN_EXPIRED`) ให้ขอลิงก์ใหม่ · ถ้าไม่ได้รับอีเมล ตรวจโฟลเดอร์ Junk ก่อนแจ้งแอดมิน

**ถาม: ทำไมชั่วโมงยังไม่ขึ้น**
ชั่วโมงจะเข้ายอดสะสมเมื่อครบ 3 อย่าง: เช็คอิน **และ** เช็คเอาต์แล้ว → อัปโหลดหลักฐานแล้ว → ผู้จัดกดอนุมัติหลักฐาน
ตรวจสถานะที่หน้า *การลงทะเบียน*; ถ้าค้างที่ "รอหลักฐาน" แปลว่ายังไม่ได้อัปโหลด

**ถาม: ลงทะเบียนแล้วสถานะยังเป็น "รออนุมัติ"**
ผู้จัดกิจกรรมต้องกดอนุมัติก่อน — ทักผู้จัดผ่านแชทในระบบได้โดยตรง

**ถาม: เข้าสู่ระบบไม่ได้ ขึ้นว่า "พยายามมากเกินไป"**
ระบบจำกัดการพยายามเข้าสู่ระบบ 5 ครั้ง/นาที เพื่อป้องกันการเดารหัสผ่าน — รอ 1 นาทีแล้วลองใหม่

**ถาม: เปลี่ยนรหัสผ่านแล้วอุปกรณ์อื่นหลุดหมด ปกติหรือไม่**
ปกติ — ระบบเพิกถอนเซสชันอื่นทั้งหมดโดยอัตโนมัติทุกครั้งที่เปลี่ยนรหัสผ่าน เพื่อความปลอดภัย
